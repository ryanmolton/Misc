Naming

Put Monday column names in braces, e.g. {Item ID}-{Project}. {today} gives today's date. A / makes subfolders, e.g. {Client}/{Item ID}-{Project}.
Example:
A folder counts as this project's if its name starts with this column's value, so renamed folders are still found.
e.g. a template file called {Item ID} Brief.docx becomes 12111781128 Brief.docx.
