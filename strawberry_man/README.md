# STRAWBERRY MAN

A ~40-second 8-bit "video game" short about Strawberry Man: no powers, unclear origin, lives in a van in Carpinteria, CA.

`strawberry_man.mp4` is the finished film (41.6 s, 1080p30, H.264 + AAC).

Nothing here comes from outside assets. The pixel art, the 5x7 bitmap font, and the NES-style chiptune score and sound effects (two pulse channels, a 4-bit stepped triangle, noise drums) are all generated by code in this folder.

```
pip install numpy pillow imageio-ffmpeg
python3 render.py            # -> strawberry_man.mp4 (~45 s to render)
```

- `gfx.py`: 320x180 canvas, bitmap font, sprite blitting, Bayer-dithered gradients
- `art.py`: the hero (with a procedural cape), seagull, burrito, and van
- `scenes.py`: the timeline and every scene (boot, title, beach, profile, battle, stage clear, night)
- `music.py`: the chiptune synthesizer and SFX
- `render.py`: builds the soundtrack, renders frames, upscales 6x with CRT scanlines, and encodes
